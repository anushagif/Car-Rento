# 🚗 Car Rental Booking App  

## 📌 Overview  
Car Rental Booking App allows users to search for rental cars by specifying **pickup and drop-off locations** along with **rental dates**. 
The app generates a **Kayak deep link** and redirects users to Kayak to complete their booking.  

## 🎯 Features  
✅ **Car Rental Search Screen**  
   - Pickup Location (Required)  
   - Drop-off Location (Optional)  
   - Pickup Date & Drop-off Date (Required)  
✅ **Date Picker** 📅 for easy date selection  
✅ **Deep Linking to Kayak** 🌍  
✅ **Form Validation** (Ensures required fields are filled)  
✅ **Jetpack Compose UI** 💡  
✅ **Dark Mode Support** (if implemented)  


## 📌 How It Works  
1️⃣ User enters **Pickup Location**, **Drop-off Location (Optional)**, and **Rental Dates**  
2️⃣ Presses **"Search on Kayak"**  
3️⃣ App **generates a deep link** based on user input  
4️⃣ Redirects user to Kayak in a web browser
